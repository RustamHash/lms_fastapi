# Как изучать проект

## Порядок изучения

1. Начните с README.md
2. Изучите архитектуру (01_architecture.md)
3. Посмотрите структуру бэкенда (02_backend.md)
4. Разберитесь с алгоритмами (03_algorithms.md)
5. Изучите фронтенд (04_frontend.md, 05_add_page.md)
6. Изучите модели БД (06_database.md)
7. Посмотрите API (07_api.md)

## Практические задачи

1. Добавить новый справочник
2. Добавить новую роль
3. Создать отчёт
4. Импорт из Excel
5. Добавить поле в модель

## Полезные команды

- Запуск бэкенда: uvicorn app.main:app --reload
- Запуск фронтенда: cd frontend && npm run dev
- Миграции: alembic upgrade head
