# Стили проекта

## Структура

- `variables.css` — CSS-переменные (палитра, отступы, радиусы)
- `login.css` — стили страницы входа
- `app-layout.css` — шапка, навигация, основная область
- `app-cards.css` — карточки, типографика
- `list-pages.css` — тулбар, кнопки, фильтры, таблица
- `list-table.css` — стили таблицы
- `context-menu.css` — контекстное меню
- `dialogs.css` — модальные окна
- `forms-wh.css` — формы
- `topology-hierarchy.css` — топология

## Палитра

См. `variables.css` для всех переменных.

### Основные цвета
- Primary: `var(--color-primary)` — #2563eb
- Success: `var(--color-success)` — #27ae60
- Danger: `var(--color-danger)` — #c0392b
- Warning: `var(--color-warning)` — #b45309

### Фоны
- Body: `var(--bg-body)` — #f4f6f8
- Card: `var(--bg-card)` — #ffffff
- Navbar: `var(--bg-navbar)` — #1f2d3d

### Текст
- Primary: `var(--text-primary)` — #222222
- Secondary: `var(--text-secondary)` — #64748b
- Light: `var(--text-light)` — #ffffff

## Отступы

- xs: `var(--spacing-xs)` — 4px
- sm: `var(--spacing-sm)` — 8px
- md: `var(--spacing-md)` — 16px
- lg: `var(--spacing-lg)` — 24px
