# План: Рефакторинг стилей

## Цель
- Ввести CSS-переменные
- Перейти на CSS Modules
- Очистить дублирования
- Удалить неиспользуемые стили
- Реорганизовать структуру

## Этапы

### 1. CSS-переменные
- Создать variables.css
- Определить палитру, отступы, радиусы, тени
- Подключить первым в App.css

### 2. Реорганизация структуры
- Разделить styles/ на components/ и pages/
- Выделить login.css из index.css
- Сгруппировать по назначению

### 3. Очистка дублирований
- Удалить повторяющиеся блоки в App.css
- Объединить одинаковые правила

### 4. Удаление неиспользуемых стилей
- Найти классы в TSX
- Сопоставить с CSS
- Удалить мёртвые

### 5. Документация
- Описать палитру
- Описать типографику
- Создать гайд
