# Доска задач rewrite

**Этот файл — очередь для нескольких чатов.** Спека этапов: `plans/rewrite-phases.md`. Слои: `ARCHITECTURE.md`.

Не копировать сюда длинные описания. Менять только строку задачи: `status`, `owner`, `notes`.

---

## Протокол агента (обязательно)

1. Прочитай **этот файл** и не бери задачу, пока не обновил строку.
2. Возьми **первую** задачу, у которой:
   - `status` = `todo`
   - все id из `blocked_by` имеют `status` = `done`
3. **Сразу** поставь `status` = `in_progress`, в `owner` — короткое имя чата или «agent» + дата (`2026-08-25`). Захват до любой работы, включая планирование: строка не должна оставаться `todo`. Не пиши код до обновления доски.
4. Не трогай строки со `in_progress` (их уже взял другой чат).
5. Одна задача на чат. Не начинай следующую, пока текущая не `done`.
6. По окончании: `status` = `done`, в `notes` — 1–2 предложения, что сделано.
7. После любой закрытой задачи — git-коммит с понятным комментарием на русском (зачем и что изменилось, не список файлов).
8. Если задача упёрлась — оставь `in_progress` и напиши блокер в `notes`, не снимай захват молча.
9. Новые CRUD-экраны и справочники **не добавлять**, пока не `done` задача `3`.

Статусы: `todo` | `in_progress` | `done`.
