# ДЕТАЛЬНЫЙ ПЛАН: Складская логистика

## 📍 Текущая проблема

### 6.1 Не учитываются max_weight и max_volume
**Файл:** app/warehouse/services/placement_service.py

При размещении товара не проверяются ограничения ячейки.

**Влияние:** Перегрузка ячеек, нарушение безопасности.

### 6.2 Нет проверки переполнения
**Файл:** app/warehouse/services/stock_service.py

При add_stock не проверяется остаточная вместимость ячейки.

**Влияние:** Переполнение, невозможность размещения новых товаров.

### 6.3 Нет проверки plan_qty vs fact_qty
**Файл:** app/warehouse/services/task_service.py

В complete_line можно указать fact_qty больше plan_qty без force.

**Влияние:** Ошибки в учете, расхождения.

### 6.4 Нет проверки дубликатов при импорте
**Файл:** app/integration/services/integration_service.py

Один и тот же документ можно импортировать несколько раз.

**Влияние:** Дубликаты документов, двойной учет.

### 6.5 Нет резервирования при создании заказа
**Файл:** app/documents/services/document_service.py

При создании документа-отгрузки не резервируется товар.

**Влияние:** Перепродажа товара, отрицательные остатки.

## 💡 Варианты решения

### Вариант A: Критические фиксы
Только 6.3 и 6.4 (проверка количества и дубликатов)
- **Плюсы:** Быстро (3 часа)
- **Минусы:** Проблемы с перегрузкой остаются
- **Сложность:** Низкая
- **Влияние:** Высокое

### Вариант B: Полное решение
Все проверки + резервирование
- **Плюсы:** Надежная складская система
- **Минусы:** Сложно (2-3 дня)
- **Сложность:** Высокая
- **Влияние:** Высокое

### Вариант C: Поэтапное внедрение
Сначала проверки количества, затем резервирование
- **Плюсы:** Управляемый риск
- **Минусы:** Дольше
- **Сложность:** Средняя
- **Влияние:** Высокое

## 🔧 Рекомендуемое решение

**Вариант C** — поэтапное внедрение.

## 📝 Шаги реализации

### Проверка количества
1. [ ] В TaskService.complete_line проверить fact_qty <= plan_qty (если plan_qty > 0)
2. [ ] Выбрасывать ValueError при превышении

### Проверка дубликатов при импорте
3. [ ] В IntegrationService.process_document проверить существование документа по номеру
4. [ ] Если существует — вернуть ошибку или пропустить

### Учет веса и объема
5. [ ] В PlacementService._find_storage_location учитывать max_weight и max_volume
6. [ ] Рассчитать текущий вес и объем в ячейке

### Резервирование
7. [ ] При создании документа-отгрузки автоматически резервировать товар
8. [ ] При отмене документа — снимать резерв

## 🧪 Как проверить

Проверить дубликаты импорта:
python scripts/import_from_ftp.py
python scripts/import_from_ftp.py
# Второй запуск должен сообщить о дубликатах

Проверить проверку количества:
curl -X POST http://localhost:8000/api/v1/warehouse/task-lines/1/complete -H "Content-Type: application/json" -d '{"fact_qty": 999, "location_id": 1}' -H "Authorization: Bearer TOKEN"
# Должен вернуть 400
