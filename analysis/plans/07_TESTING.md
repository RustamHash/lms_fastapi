# ДЕТАЛЬНЫЙ ПЛАН: Тестирование и CI/CD

## 📍 Текущая проблема

### 7.1 Полное отсутствие тестов
**Файл:** Нет директории tests/

**Влияние:** Невозможность безопасного рефакторинга, регрессии.

### 7.2 Нет CI/CD
**Файл:** Нет .github/workflows/

**Влияние:** Ошибки попадают в production.

### 7.3 Нет проверки типов
**Файл:** pyrightconfig.json существует, но не используется в CI.

**Влияние:** Ошибки типов не отлавливаются.

## 💡 Варианты решения

### Вариант A: Минимальное тестирование
Только unit-тесты для критических сервисов
- **Плюсы:** Быстро (1 день)
- **Минусы:** Не покрывает API
- **Сложность:** Средняя
- **Влияние:** Среднее

### Вариант B: Полное тестирование
Unit + Integration + E2E + CI/CD
- **Плюсы:** Максимальная надежность
- **Минусы:** Долго (неделя)
- **Сложность:** Высокая
- **Влияние:** Высокое

### Вариант C: Прагматичное тестирование
Unit + Integration для API + базовый CI
- **Плюсы:** Хорошее покрытие за разумное время (3 дня)
- **Минусы:** Нет E2E
- **Сложность:** Средняя
- **Влияние:** Высокое

## 🔧 Рекомендуемое решение

**Вариант C** — начать с unit и integration тестов.
